<h2>معرفی پروژه</h2>

<p>این پروژه در چارچوب درس برنامه‌نویسی پیشرفته دانشگاه صنعتی شریف توسعه یافته است. بازی تمدن، یک بازی استراتژیک نوبتی با الهام از مجموعه بازی‌های Civilization است که در آن بازیکن با مدیریت منابع، توسعه شهرها، پیشرفت فناوری و تعامل با سایر نیروها، قلمرو خود را گسترش می‌دهد.</p>

<h2>امکانات بازی</h2>

<ul>
  <li>نقشه شش‌ضلعی، تولید نقشه و ویرایشگر نقشه سفارشی</li>
  <li>مدیریت اقتصاد، منابع، تجارت، ساختمان‌ها و فناوری‌ها</li>
  <li>تولید نیرو، مسیریابی، نبرد و گسترش قلمرو</li>
  <li>رفتار خودکار دشمنان، تعامل با قبایل، فصل‌ها و بلایای طبیعی</li>
  <li>رابط گرافیکی، موسیقی پس‌زمینه و ذخیره و بازیابی بازی</li>
</ul>

<h2>طراحی و پیاده‌سازی</h2>

<p>پروژه با زبان Java و رویکرد برنامه‌نویسی شیءگرا پیاده‌سازی شده است. ساختار کد بر پایه تفکیک مدل، نما و کنترل‌گر (MVC) شکل گرفته و رابط گرافیکی با Swing توسعه یافته است. برای مدیریت ساخت پروژه از Maven و برای آزمون بخش‌های مختلف منطق بازی از JUnit 5 استفاده شده است.</p>

<h2>اجرای پروژه</h2>

<p>پس از نصب JDK سازگار با Java 8 و Maven، دستورات زیر را در پوشه اصلی پروژه اجرا کنید:</p>

</div>

```bash
mvn clean compile
mvn exec:java
```

<div dir="rtl" align="right">

<p>برای اجرای آزمون‌ها:</p>

</div>

```bash
mvn test
```
